Installing AquaDiscordSRV

A step-by-step walkthrough for wiring up the Discord ⇄ Minecraft bridge on your Aquamarine server — from dropping in the plugin to getting your first message across.

Before you start

Prerequisites

  • An Aquamarine server you can restart and edit files on.
  • A Discord account, and permission to manage the server (guild) you want to bridge — you'll need Manage Server to invite a bot.
  • Shell or SFTP access to the server's plugins/ folder.
💡

Everything below happens once. After setup, the bridge runs on its own — no need to touch Discord's developer portal again unless you reset the token.

Step 1

Install the plugin

  1. Extract the plugin into your plugins folder

    Unzip AquaDiscordSRV.zip so the AquaDiscordSRV folder itself (containing plugin.yml) sits directly inside your server's plugins/ directory.

    Directory layout 
    plugins/
└── AquaDiscordSRV/
    ├── plugin.yml
    ├── resources/config.yml
    └── src/aquadiscordsrv/...

  2. Restart the server once

    This generates plugins/AquaDiscordSRV/config.yml from the defaults. The bridge stays off until you finish the steps below — nothing will try to contact Discord yet.

Step 2

Create a Discord application and bot

  1. Create the application

    Go to the Discord Developer Portal, click New Application, and give it any name — this is what shows up as the bot's username.

  2. Add a bot user

    Open the Bot tab in the left sidebar and click Add Bot (on newer apps this may already be created for you).

  3. Turn on the privileged intents

    Still on the Bot tab, scroll to Privileged Gateway Intents and enable:

    • Server Members Intent
    • Message Content Intent — without this, the bot receives messages with empty content and can't relay anything into the game

  4. Copy the bot token

    Click Reset Token, then copy the value it shows you. Keep Public Bot switched off so random users can't add it to their own servers.

    ⚠️
    Treat this token like a password.

    Anyone who has it can control your bot. Don't paste it into chat, a public repo, or a screenshot.

Step 3

Invite the bot and set permissions

  1. Generate an invite link

    Open the OAuth2 → URL Generator tab. Under Scopes, check bot. Under Bot Permissions, check the boxes below, then open the generated URL and add the bot to your server.

    PermissionWhy AquaDiscordSRV needs it
    View ChannelRead the chat (and console) channels you configure
    Send MessagesPost in-game chat, join/leave, and death messages
    Read Message HistoryPoll for new messages since the last check

    That's the full list — this plugin doesn't touch roles, nicknames, or bans, so it doesn't ask for those permissions.

  2. Turn on Developer Mode in Discord

    In your own Discord client: User Settings → Advanced → Developer Mode. This adds a "Copy Channel ID" option when you right-click a channel.

  3. Copy your chat channel's ID

    Right-click the text channel you want mirrored in-game and choose Copy Channel ID. You'll paste this into config.yml next.

Step 4

Configure the plugin

Open plugins/AquaDiscordSRV/config.yml and fill in three values:

config.yml 
Enabled: true

BotToken: "paste-your-bot-token-here"

Channels:
  Chat: "1234567890123456789"   # the channel ID you copied

Everything else in the file has a sensible default — colors, message wording, and the poll interval can all be tuned later. Run /discordsrv reload in-game or from console to apply changes without a full restart.

Step 5

Verify it's working

  1. Check the startup log

    After reloading, the console should print Connected to Discord as bot user … followed by Bridge is up - relaying chat with Discord channel …. Your Discord channel should also receive a server-started notice.

  2. Run the status command

    In-game or console 
    /discordsrv status

  3. Send a test message both ways

    Type in the Discord channel — it should appear in-game within a few seconds (the default poll interval). Then chat in-game and confirm it shows up in Discord.

Optional

Extra features worth turning on

Chat as the player, with their skin as the avatar

In the Discord channel's Integrations → Webhooks settings, create a webhook and copy its URL into WebhookUrl in config.yml. In-game chat will then post through the webhook using the player's name and rendered skin, instead of showing as the bot.

Mirror the console to a Discord channel

Set Channels.Console to a second channel ID. New lines written to server.log get batched and posted there on the same interval as chat.

⚠️
Letting Discord run console commands

ConsoleCommandExecution: true makes every message posted in Channels.Console run as a server console command — full access, no confirmation. Only enable this if that channel is restricted to trusted staff, ideally in a category only they can see or post in.

Customize the message wording

The Formats block in config.yml controls chat, join, leave, death, and Discord-to-game templates, using placeholders like {player}, {message}, {online}, and {max}.

If something's off

Troubleshooting

The console logs a warning and the bridge won't turn on

This means BotToken or Channels.Chat is still blank or left at the placeholder value. Double check both are filled in and the channel ID is the 17–19 digit number from "Copy Channel ID", not the channel's name.

Messages don't relay from Discord into the game

Almost always a missing Message Content Intent — without it, Discord sends every message with blank content. Re-check the Bot tab in the Developer Portal, then /discordsrv reload.

In-game chat isn't appearing in Discord

Confirm the bot actually has View Channel and Send Messages on that specific channel — permissions set at the server level can still be overridden per-channel.

Discord replies feel slow

Incoming messages are picked up by polling rather than a live connection, so there's a small built-in delay. Lower PollIntervalSeconds in config.yml if you want it snappier, but keep it at 3 seconds or higher to stay comfortably within Discord's rate limits.

I want role sync, ban sync, or account linking

These need a persistent connection to Discord's Gateway with a live member cache, which isn't something Aquamarine's plugin API currently exposes to plugins — so they're intentionally left out rather than half-implemented. The chat bridge, event relay, and console tools above cover what's realistically buildable on this API today.
